# 智联求职助手 · JobPilot

一个跑在自己电脑上的**求职自动化工作台**：Electron 内嵌浏览器 + 本地大模型接入，把「读简历 → 改简历 → 找岗位 → 打分 → 投递 → 回 HR」串成一条能自己跑的流水线。

不是爬虫脚本合集，也不是无脑群发工具。它的核心是**真实**：简历不许吹、回复不许像 AI、匹配要读懂人话、动作要控频率。

> 项目由一位 40 岁上下的 B 端销售在求职期间写出来自用，代码还很粗糙，很多地方靠"能用就行"堆出来的。**公开出来是想请各位大佬帮忙把它做扎实、做通用**——尤其是多招聘网站适配、DOM 选择器维护、模型调度这几块，非常需要有人一起搞。

## 它能做什么

| 模块 | 做的事 | 关键设计 |
| --- | --- | --- |
| 简历 | 读在线简历 / 上传 docx、pdf，结构化解析后重写 | 先结构后措辞：公司、时间、职位原样保留，只改 bullet；两道门禁防吹牛 |
| 简历门禁 | `truthGate()` + `toneDownClaims()` | 新增数字必须在原文出现；`参与/协助`不许升级成`主导/统筹`；禁用词（行业领先/100%/零故障）直接打回；结束时间不许穿越到未来 |
| 需求理解 | 把自由输入变成结构化偏好 | "一年出差 300 天、最好自驾" → `travelDays:300, selfDrive:true`，再参与岗位加减分 |
| 岗位匹配 | 规则六维粗排 + 大模型读 JD 精排 | `final = 0.45×规则 + 0.55×模型`；模型判 no 且低于 40 不进投递队列；按规则分排队、限时预算，避免被免费模型拖死 |
| 投递 | 按阈值自动投，可 dry-run | 每小时/每日配额、间隔浮动、冷却、连续失败熔断、黑名单与类型过滤（快递/外卖/保险/保健品/匿名电销） |
| 消息 | 打开消息页自动抓会话、自动回 HR | **先做 HR 心理分析再写回复**：意图/阶段/潜台词/风险/该说/先别说/可反问；要简历只点「同意」不发文字；同一句话三天只回一次 |
| 记忆 | 沉淀每类问题的处理经验与策略版本 | 问题分类计数、经验条目、策略版本号，回复时会带上"上次这种情况怎么处理" |
| 空闲学习 | 不刷论坛水贴，按真问题搜公开文章 | 12 个求职/HR 心理主题 → 站内检索 → 压成三点认知 → 存 `data/knowledge.json`，回复时只当背景、不背给 HR 听 |
| 日志 | 30 天滚动，事件 + 每轮运行记录 | 投递/回复每一步都有 trace，出问题能回放 |

界面是左侧一条窄面板（简历/需求/岗位/版本/消息/知识库/报表/日志/设置）+ 右侧内嵌浏览器，所有操作都在一个窗口里完成。

## 架构一眼看懂

```
main.js                  Electron 主进程：窗口、IPC、自动流程编排、空闲学习定时
preload.js               最小桥（invoke / on）
src/
  ui/                    左侧面板（原生 HTML + JS，没有框架）
  engine/
    resume.js            简历清洗、结构化重建、压夸、反吹牛校验
    parse.js             简历文本 → experiences / projects / education
    intent.js            自由需求 → 结构化偏好 + 岗位加减分
    score.js             六维加权打分 + 偏好增量
    matchLlm.js          规则粗排 + 模型精排（批量、并发、限时、缓存）
    hrMind.js            HR 心理分析（意图/潜台词/策略），模型不可用走规则
    personaRules.js      回复规则 R01–R18（要简历点同意、不重复、不反问式收尾…）
    autoflow.js          投递与回复的编排，串起上面所有模块
    guard.js             频率控制与熔断
    policy.js            岗位类型过滤
    memory.js            经验沉淀与策略版本
    knowledge.js         本地知识库读写
    idleLearn.js         空闲学习（搜索 → 抽取 → 压缩）
    llm.js               OpenAI 兼容客户端 + 多路由兜底
  data（运行时生成，不入库）  简历、需求、设置、记忆、知识库、缓存、备份
scripts/
  learn.js               手动学一条
  learn-daemon.js        常驻每 30 分钟一条
```

## 快速开始

前置：Windows 10/11、Node.js 20+（建议 22）。

```bash
git clone <你的仓库地址>
cd zhaopin-assistant
npm install
npm start
```

首次启动会生成 `data/` 目录和默认配置。左侧「设置」里填模型信息，右侧登录招聘网站，然后：

1. 「简历」页抓在线简历 → 点优化 → 看 diff → 写回；
2. 「需求」页用大白话写你要什么（城市、薪资、出差强度、要不要自驾、明确不要什么）；
3. 「岗位」页搜索 → 打分 → 选中的投递；
4. 「消息」页打开即抓会话，自动出稿（默认只出稿不发送，确认后再开自动发送）。

### 接模型

任何 OpenAI 兼容接口都能用，填 `baseUrl / model / apiKey` 即可。作者自己用的是局域网里的免费聚合服务，**仓库里不含任何密钥**，也不推荐把 key 提交进 Git。

`llm.js` 内置几条免费路由兜底（FreeLLMAPI / OFM / g4f / Pollinations），主路由 429 时会自动换下一条。免费路由的脾气是：单路由连续调用必限流，所以关键小请求都做了超时和降级，模型不可用时整套流程退化成规则版，不会卡死。

## 已知限制（不藏着）

- **站点支持已扩到 5 家，但只有智联和 51job 实页验证过**：智联、前程无忧、猎聘、拉勾、BOSS 直聘都接进了 `sites.js`，选择器抓不到会自动退回启发式扫描；BOSS 风控最严、未登录直接跳登录页，拉勾列表本身不展示公司名。
- **免费模型撑不住全量精排**：实测 6 个岗位约 96 秒；60 个岗位按这速度要十几分钟。所以现在是「规则分全量 + 模型按分数排队、限时预算」，到点没轮到的保留规则分。
- **反爬与风控**：有频率控制、冷却和熔断，但不能保证不被平台识别。请不要拿它做批量骚扰，账号风险自己承担。
- **简历优化仍有两版**：规则结构化版稳定可用；纯模型重写版在小模型上容易吃段落边界，正在改成"逐段 JSON 改写 + 校验"。
- **只做过 Windows**：Electron 本身跨平台，但路径、日志目录、部分快捷键是 Windows 习惯。

## 最想请大佬们帮的几件事

1. **站点适配继续补（最急）**
   `sites.js` 已经是站点注册表（home / 简历页 / 消息页 / 搜索模板 / 选择器 / 投递与 IM 能力），`scraperMulti.js` 负责按配置生成页面脚本并带启发式兜底。现在智联、51job、猎聘、拉勾、BOSS 都接了一半，缺的是：各站会话列表与发消息的真实类名、BOSS 的风控应对、脉脉/领英这类新站。设计草案见 `docs/ADDING-A-SITE.md`。
2. **DOM 选择器维护**
   给每个站点加"选择器自检"：启动时跑一遍关键节点，失效就降级成人工接管并报警，而不是静默失败。
3. **模型调度**
   多路由、并发、限流、超时、JSON 校验重试的统一封装；能接本地小模型（Ollama / llama.cpp）做离线兜底。
4. **简历改写质量**
   逐段改写 + 条数一致 + 数字可溯源这三条已经有了，缺的是更好的 prompt 与 few-shot，以及中英双语简历。
5. **HR 心理分析的准确率**
   现在是 12 类意图 + 潜台词模板 + 模型校正，欢迎做招聘/猎头/HR 的朋友来骂醒它：哪些潜台词是错的、哪些话术一看就假。
6. **UI**
   现在是很朴素的原生面板，欢迎做成真正好用的工作台（时间线、漏斗、对比视图）。
7. **测试**
   目前只有若干手工脚本，没有单测框架。想补 vitest：`intent.parse`、`truthGate`、`guard` 配额、`hrMind` 规则分支最值得先测。

有想法直接开 Issue，写代码就提 PR。哪怕只是"这个站点的选择器我帮你改对了"，都非常有用。

## 合规与边界

- 仅供**个人求职**使用，请遵守各招聘平台的服务条款与 robots 约定。
- 不要用它群发、骚扰 HR、伪造经历；简历门禁就是为了防这个。
- 不要提交任何真实简历、手机号、密钥、公司内部数据到仓库；`data/` 已在 `.gitignore` 里。
- 项目按 MIT 开源，不提供任何形式的可用性担保。
